# Gate Rule

The Gate Rule is the MRE's hard limit on "I win" buttons: [[exotic-tag|Exotic Tags]] — the most powerful effects in the system — can only target characters who are already in [[gate-state|Gate State]]. You cannot Dominate a functioning mind. You cannot Erase a person the world still acknowledges. You must break the gate before you walk through it. The killshot is earned, never given.

---

## The Rule

> **Exotic effects can only target characters whose relevant [[pool|Pool]] is at 0.**

Each Exotic Tag specifies which Pool must be at zero:

- **Domination** requires Mental Pool = 0
- **Hostile Transformation** requires Physical Pool = 0
- **Erasure** requires Social Pool + Physical Pool = 0
- **Execution** requires any Pool = 0

If the target's relevant Pool is above 0, the Exotic effect cannot be applied — regardless of how powerful the attacker is. The rule is structural, not numerical. No amount of [[margin|Margin]] overrides it.

---

## The Specificity Relaxation

One exception: if the Exotic effect carries a [[keyword|Keyword]], the [[specificity-modifier|Specificity Modifier]] relaxes the threshold from 0 to **25% of the relevant Pool's maximum value**. A typed Domination attempt can target a character at Mental Pool ≤ 25% (e.g., ≤ 6 for a character with maximum Mental Pool 24) rather than requiring Mental Pool = 0.

This relaxation makes typed Exotic effects more accessible — but also more counterable, because the Keyword subjects them to elemental matchup vulnerabilities. The tradeoff is [[creative-reciprocity|Creative Reciprocity]] applied to the endgame.

---

## You Died Variant

> **You Died sub-game:** In You Died, the Gate Rule operates identically — chip-pool Gate State requirements must be met before Exotic card effects can target. The Specificity Relaxation threshold is unchanged.
