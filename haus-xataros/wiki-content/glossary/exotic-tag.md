# Exotic Tag

Exotic Tags are the MRE's ultimate moves — the most devastating effects in the system, locked behind the hardest requirement: your target must already be broken. A character in [[gate-state|Gate State]] (any [[pool|Pool]] at zero) is vulnerable. A character above zero is not. This is the [[gate-rule|Gate Rule]], and it is absolute. You cannot Dominate a mind that hasn't been shattered. You cannot Erase a person the world still recognizes. The killshot must be earned. Exotic Tags are the reward for earning it.

---

## The Five Exotic Tags

| Tag | Effect Rank Cost | Gate Requirement | Effect |
|:----|:----------------:|:-----------------|:-------|
| **Domination** | 5 | Target Mental Pool = 0 | Seize control of the target's actions |
| **Hostile Transformation** | 4 | Target Physical Pool = 0 | Force the target into a different form |
| **Erasure** | 5 | Target Social + Physical Pool = 0 | Remove the target from existence |
| **Resurrection** | 5 | Target dead within 1 Scene | Restore a dead character to life |
| **Execution** | 1 (at Rank 5 only) | Target in any Gate State | Instant kill / permanent removal |

These costs are high. A Domination-capable Power requires 5 Effect Ranks devoted to a single tag — most of a low-Intensity Power's entire budget. Building toward Exotic effects is a strategic commitment that shapes the entire character.

---

## The Specificity Relaxation

The [[gate-rule|Gate Rule]] has one exception. If an Exotic effect carries a [[keyword|Keyword]], the [[specificity-modifier|Specificity Modifier]] relaxes the Gate State threshold from Pool = 0 to **Pool ≤ 25% of maximum**. A typed Domination attempt can target a character at 25% Mental Pool rather than waiting for zero.

This makes typed Exotics more accessible — but also more counterable, because the Keyword subjects them to type matchup vulnerabilities. The tradeoff is [[creative-reciprocity|Creative Reciprocity]] extended to the endgame.

---

## Strategic Notes

**Exotic Tags create two-phase strategies.** Phase one: deal enough damage to push the target into Gate State (or below 25% for typed effects). Phase two: land the Exotic. Teams that coordinate — one member dealing damage, another holding the Exotic power — are executing this strategy deliberately.

**The [FINISHER] tag is the budget alternative.** Any attack carrying [FINISHER] auto-incapacitates a Gate State target on any successful hit, regardless of [[margin|Margin]]. It doesn't Dominate, Transform, or Erase — it just ends the fight. [FINISHER] costs far less than a full Exotic Tag but offers no control over *how* the target is removed.

---

## You Died Variant

> **You Died sub-game:** In You Died, Exotic Tags function identically — card-based effects locked behind chip-pool Gate State requirements. The Specificity Relaxation and Gate Rule apply without modification.
