# Gate State

Gate State is the end of the line — the moment a character's capacity in one domain collapses to nothing. When any single [[pool|Pool]] reaches 0, the character enters Gate State: scene removal. Not death. Not necessarily unconsciousness. The character is functionally unable to continue participating in the current conflict. What they *look* like depends on which Pool broke. What they are *vulnerable to* is universal — and terrifying. Gate State is the lock. The [[exotic-tag|Exotic Tags]] are what waits on the other side.

---

## The Three Zeroes

Gate State means different things depending on which Pool emptied:

| Pool at Zero | Narrative Meaning |
|:-------------|:-----------------|
| **Physical** | The body has failed. Unconscious, broken, bleeding out. The closest to traditional "defeat." |
| **Mental** | The mind has broken. Catatonic, dissociated, overwhelmed. The lights are on but no one is home. |
| **Social** | The identity has dissolved. Public humiliation, complete loss of composure, existential collapse. Standing but no one. |

All three are mechanically equivalent. Social Gate State is as real and total as Physical Gate State. The character whose reputation was surgically destroyed and the character whose skull was cracked — both are done. The MRE does not rank suffering.

---

## What Gate State Enables

A character in Gate State becomes vulnerable to **[[exotic-tag|Exotic Tags]]** — the most powerful and devastating effects in the system, locked behind the requirement that you break someone *before* you can finish them:

| Exotic Tag | Gate Requirement | What It Does |
|:-----------|:----------------|:-------------|
| **Domination** | Target Mental Pool = 0 | Seize control of the target's actions |
| **Hostile Transformation** | Target Physical Pool = 0 | Force the target into a different form |
| **Erasure** | Target Social + Physical Pool = 0 | Remove the target from existence |
| **Execution** | Target in any Gate State | Instant kill / permanent removal |

Additionally, any attack carrying the **[FINISHER]** tag auto-incapacitates a Gate State target on any successful hit, regardless of [[margin|Margin]].

This is the [[gate-rule|Gate Rule]]: Exotic effects can only target characters already in Gate State. You cannot Dominate a conscious mind. You cannot Erase a person the world still remembers. The killshot must be earned.

---

## The Specificity Relaxation

The Gate Rule has one exception. If an Exotic effect carries a [[keyword|Keyword]] (an elemental type), the [[specificity-modifier|Specificity Modifier]] relaxes the Gate State threshold from 0 to **25% of the relevant Pool**. A typed Domination attempt can target a character at Mental Pool ≤ 25% rather than requiring Mental Pool = 0.

This makes typed Exotic effects more accessible but also more counterable — elemental typing carries both the advantage of earlier access and the vulnerability of type matchups through the [[hexagon-circuit|Hexagon]] and [[triangle-circuit|Triangle Circuits]].

---

## When Gate State Is Checked

Gate State is checked during the [[cleanup-phase|Cleanup Phase]] (Phase 5 of the [[poker-hand-model|Poker-Hand Model]]), *after* all actions for the Beat have resolved. Under the current working ruling, a character whose Pool reaches 0 during the [[resolution-phase|Resolution Phase]] completes all their declared actions for the Beat before Gate State removes them.

This means a character who is fatally hit at Priority +3 can still fire their own ASAP-band power before being removed at Cleanup. The declared intent lands even through the moment of defeat. The MRE's model is deliberately theatrical: what you committed to, you get to do.

> **⚠️ Source Note:** The Gate State timing ruling (checked at Cleanup vs. checked immediately during Resolution) is a live design question flagged in [[open-questions/gate-state-timing|Gate State Timing]]. The Cleanup check is the current working ruling, applied during the Tournament Prototype (Duel 6: Shore vs. Wrex). No Decision Log entry yet formalizes this ruling.

## Strategic Notes

**Know which zero they fear.** Every character has a weakest Pool — the domain where their [[stat|Stat]] is lowest, their [[dice-hand|Dice Hand]] is thinnest, and the [[entropic-cap|Entropic Cap]] bites first. A Physical bruiser with Social Stat 1 has a Social Pool of 12. Twelve points of Social damage, and the bruiser is standing there with a shattered identity. The smart opponent targets the weak Pool, not the strong one.

**Gate State is a setup, not an ending.** In many fights, the real play is to push a target into Gate State in one domain so an Exotic effect can land. A team that coordinates — one member dealing Mental damage, another holding a Domination power — is executing a two-phase strategy: break the gate, then walk through it.

## You Died Variant

> **You Died sub-game:** In You Died, Gate State triggers when a chip pool reaches zero. The three-domain structure, Exotic Tag vulnerability, and Gate Rule all apply identically. Card-based Exotic effects use the same Gate requirements as dice-based ones.
